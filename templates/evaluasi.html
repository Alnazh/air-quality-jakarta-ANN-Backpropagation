Metrik Evaluasi
Kurva Training & Validation Loss
Train Loss (hijau) = kesalahan di data training. Val Loss (oranye putus-putus) = kesalahan di data uji. Keduanya harus turun dan bertemu. Jika Val Loss naik sementara Train Loss turun, model mulai menghafal data (overfitting). Garis merah = epoch terakhir sebelum training berhenti.
Aktual vs Prediksi (Sampel Uji)
Garis biru = nilai ISPU sesungguhnya dari data uji. Garis merah putus = hasil prediksi model. Semakin sering kedua garis berhimpit, semakin akurat model.
Kurva Akurasi per Epoch
Grafik ini menunjukkan akurasi model selama training. Idealnya kedua garis naik bersama dan stabil di angka tinggi.
Confusion Matrix
Cara membaca: Baris = kategori aktual (kenyataan). Kolom = kategori prediksi (hasil model). Hijau diagonal = prediksi benar. Merah = prediksi salah. Angka besar di luar diagonal = kelemahan model.
