Upload Dataset Opsional
Buka →

Kapan perlu upload dataset?

  • Jika kamu punya data ISPU yang lebih baru atau dari kota lain
  • Jika ingin melatih model dengan data custom untuk penelitian
  • Data upload akan otomatis menggantikan dataset bawaan

Format yang diterima:

  • File CSV atau Excel (.xlsx)
  • Kolom wajib: tanggal, stasiun, pm10, pm25, so2, co, o3, no2, max, categori
  • Ada tombol Reset ke Dataset Bawaan jika ingin kembali
4
Prediksi ISPU Wajib sebelum Evaluasi
Buka →
Langkah 1 — Konfigurasi Model
  1. Pilih stasiun pemantau (atau "Semua Stasiun")
  2. Pilih mode: Regresi atau Klasifikasi
  3. Atur arsitektur: jumlah neuron H1, H2, H3
  4. Sesuaikan epochs, learning rate, dropout, batch size
  5. Klik "Mulai Latih Model"
Langkah 2 — Lihat Hasil Training
  • Kurva loss per epoch muncul otomatis
  • Grafik aktual vs prediksi (mode regresi)
  • Akurasi per epoch (mode klasifikasi)
  • Training log real-time di panel kiri
Langkah 3 — Prediksi Data Baru
  • Isi nilai polutan (PM10, PM25, SO2, CO, O3, NO2)
  • Pilih bulan & hari untuk konteks musiman
  • Klik "Prediksi Sekarang"
  • Hasil muncul: nilai ISPU + kategori + warna
5
Evaluasi Model
Buka →
Syarat: Model harus sudah dilatih di halaman Prediksi ISPU terlebih dahulu.
  • Pilih stasiun dan mode (regresi/klasifikasi)
  • Klik "Tampilkan Evaluasi"
  • Lihat metrik: MSE, RMSE, MAE, R² (regresi) atau Accuracy (klasifikasi)
  • Kurva training & validation loss
  • Grafik aktual vs prediksi atau confusion matrix
Regresi vs Klasifikasi — Apa Bedanya?
Mode Regresi
Output berupa angka ISPU numerik, contoh: 87.4
Cocok untuk: memperkirakan seberapa buruk kualitas udara secara presisi
Metrik: MSE, RMSE, MAE, R²
Mode Klasifikasi
Output berupa kategori ISPU, contoh: SEDANG (87%)
Cocok untuk: keputusan cepat apakah udara aman atau berbahaya
Metrik: Accuracy, Confusion Matrix
Rekomendasi: Latih keduanya untuk mendapat analisis yang lebih lengkap. Model tersimpan terpisah berdasarkan stasiun + mode.
